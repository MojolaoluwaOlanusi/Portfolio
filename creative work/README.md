# Creative Work Library

Use this folder as the media source for the portfolio.

Structure:

- 3d/
  - models/
  - archviz/
  - product-renders/
  - animations/
- graphic-design/
- video-editing/
- web-dev-projects/

Naming convention:
- Use descriptive names like `moviehub-pic-1.jpg`, `snitch-shot-01.png`, `product-render-hero.webp`
- Add files in the relevant folder depending on the project type
- For videos, keep the file extension as `.mp4`, `.mov`, or `.webm`

The portfolio reads text content from the portfolio/content folder and uses this media folder as the storage area for visuals and video assets.
